One line of office comedy. `main.ts` writes a single joke — at most 200
characters — to `/output/entry.txt`. The writing is the whole contest: a judge
model compares jokes head to head, and the funniest one takes the prize.

Run it with Node 22.18 or later:

```sh
node main.ts
```

The joke is deterministic: every run writes the same line.
